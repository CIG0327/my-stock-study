# 📈 나만의 미국주식 학습플랜 (Antigravity × @orlandocampus)

[**올랜도 킴 미국주식 (`@orlandocampus`)**](https://www.youtube.com/@orlandocampus) 채널의 **2026년 영상 분석 틀을 벤치마킹**하여, **기본적 분석(대차대조표·손익·밸류에이션) 50% × 기술적 분석(이동평균선·매물대·차트) 50%**를 매일 균형 있게 학습하고 내 레벨 성장을 진단받는 모바일 주식 학습 시스템입니다.

---

## ✨ 5대 핵심 기능

1. **🎯 올랜도 킴 2026 영상 5단계 벤치마킹 & 일일 자동 업데이트**
   - `매크로/시황 → 스마트 머니(13F/내부자) → 기본적 분석(대차대조표/손익) → 기술적 분석(이평선/매물대) → 조건부 시나리오 대응`의 5단계 프레임워크로 영상을 해부합니다.
   - **새 영상이 없는 날에도 멈추지 않는 스마트 연속 학습 큐**: 당일 신규 영상이 업로드되지 않아도, 아직 학습하지 않은 2026년 핵심 영상 + 미학습 개념을 자동으로 조합하여 매일 아침 새로운 스터디를 구성합니다.
2. **🌱 초보자부터 마스터까지: AI 레벨 진단 & 5대 역량 성장 리포트**
   - `Lv.1 주린이 입문자` → `Lv.2 재무·차트 해독가` → `Lv.3 대차대조표 & 수급 분석가` → `Lv.4 실전 밸류 & 시나리오 전략가` → `Lv.5 올랜도 킴 마스터 독립 투자자`까지 내 성장이 경험치(XP)와 **5대 역량 오각형 레이더 차트**로 실시간 시각화됩니다.
3. **🎁 구독자 요청 종목 이벤트 스터디 & 💼 내 보유종목 실전 대조**
   - 영상에 등장하는 **구독자 요청/특집 종목(`PLTR` 팔란티어, `ORCL` 오라클, `GE` GE에어로스페이스, `MU` 마이크론 등)**을 이벤트 미션(+50 XP)으로 공부합니다.
   - 내 보유 종목(`TSLA`, `IONQ`, `HOOD`, `JOBY`, `SATL`, `TSLL`)의 평단가 대비 차트 지지·저항선과 대차대조표 체력 등급을 한눈에 비교합니다.
4. **✍️ 단원별 마스터 테스트 & 🔄 오답 리마인드 복습 노트**
   - 6개 단원 학습 후 5문항 마스터 테스트를 치르고, 틀린 문제는 **오답 리마인드 복습 노트**에 자동 등록되어 완벽히 이해할 때까지 리마인드해 줍니다.
5. **📱 휴대폰 모바일 웹앱(PWA) + 디스코드 1분 스포일러 퀴즈 브리핑**
   - `web/index.html`을 휴대폰이나 PC 브라우저로 열면 앱처럼 학습할 수 있으며, 매일 아침 휴대폰 디스코드로 **오늘의 영상 인사이트 + 검은색 가림막(`||정답||`) 터치형 1분 퀴즈**가 전송됩니다.

## 🚀 바로 시작하기

### 1. 일일 자동 업데이트 & 스터디 생성 실행
```bash
python "주식공부하기(Anitigravity)/run_daily_study.py"
```
- 실행 시 자동으로 `web/data.js`와 `docs/` 마크다운 학습 노트 3종이 최신화되며, 휴대폰 디스코드로 오늘의 학습 브리핑이 전송됩니다.

### 2. 모바일/웹 학습 앱 열기
- [`web/index.html`](web/index.html) 파일을 더블 클릭하거나 GitHub Pages로 접속하면 **5개 탭(오늘의공부 / 6단원학습 / 종목·이벤트랩 / 진단·리마인드 / 26년영상)**이 탑재된 모바일 학습 앱이 실행됩니다.
